# Shakti AI Agency Website

A responsive, original one-page website for an agency that builds AI agents for SMEs and enterprises.

## Run locally

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before launch

- Replace the placeholder email, locations and legal links.
- Connect the contact form to a CRM, email service or backend endpoint.
- Review compliance and security claims against your actual practices.
- Add analytics, cookie consent and privacy policy as required.
